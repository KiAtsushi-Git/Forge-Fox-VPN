# ForgeFox VPN Server Setup Guide

Этот гайд поможет вам настроить любой Linux-сервер (рекомендуется Ubuntu/Debian) для работы с нашим кастомным SSH VPN ядром `ForgeFox`.

## Требования к серверу

Наше Rust-ядро использует протокол SSH для создания VPN-туннеля (L3). Для того чтобы сервер мог корректно принимать подключения, создавать интерфейс `tun0` и маршрутизировать трафик в интернет, необходимо настроить несколько базовых параметров ОС.

### Необходимые настройки:
1. **PermitRootLogin yes** — Ядро авторизуется от имени `root`, так как только root может создавать TUN-интерфейсы и управлять `ip link`.
2. **PermitTunnel yes** — Разрешает создание туннельных интерфейсов через SSH.
3. **IP Forwarding** — Включает маршрутизацию IP-пакетов между интерфейсами (чтобы пакеты из `tun0` шли в интернет).
4. **NAT (MASQUERADE)** — Подменяет IP-адреса клиентов из сети `10.0.0.0/24` на реальный IP-адрес сервера при выходе в интернет.

## Быстрая автоматическая установка (Рекомендуется)

Вы можете настроить сервер в одну команду с помощью нашего скрипта.
Просто скопируйте этот скрипт на ваш сервер и запустите его от имени root:

```bash
chmod +x install.sh
./install.sh
```

## Ручная установка (Шаг за шагом)

Если вы хотите настроить сервер вручную, выполните следующие команды:

**1. Включите IP-форвардинг:**
```bash
sysctl -w net.ipv4.ip_forward=1
echo "net.ipv4.ip_forward=1" > /etc/sysctl.d/99-forgefox-vpn.conf
sysctl -p /etc/sysctl.d/99-forgefox-vpn.conf
```

**2. Загрузите модуль TUN:**
```bash
modprobe tun
echo "tun" > /etc/modules-load.d/tun.conf
```

**3. Настройте NAT:**
Найдите ваш основной интернет-интерфейс (обычно `eth0` или `ens3`):
```bash
ip route show default
```
Затем добавьте правило маскарадинга (замените `eth0` на ваш интерфейс):
```bash
iptables -t nat -A POSTROUTING -s 10.0.0.0/24 -o eth0 -j MASQUERADE
```
*(Не забудьте сохранить правила `iptables`, например через `iptables-save` или `netfilter-persistent`)*

**4. Настройте SSH (/etc/ssh/sshd_config):**
Убедитесь, что в файле `/etc/ssh/sshd_config` раскомментированы и установлены следующие параметры:
```text
PermitRootLogin yes
PermitTunnel yes
```
Перезапустите SSH-сервер:
```bash
systemctl restart ssh
```

Готово! Теперь ваш сервер готов принимать подключения от приложения ForgeFox VPN. Добавьте в приложение ссылку вида `ssh://root:пароль@IP_СЕРВЕРА:22#Имя_Сервера` и подключайтесь!
